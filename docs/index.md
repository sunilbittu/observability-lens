# observability-lens

OpenTelemetry-native observability: metrics, events, logs, and traces in one place.

!!! warning "Status: prototype"
    Under active development. Not production-ready.

## What it is

- OpenTelemetry Collector for OTLP ingestion
- ClickHouse for storage
- Query API and web UI for traces, logs, metrics, events
- Alert engine with webhook notifications
