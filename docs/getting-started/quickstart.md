# Quickstart

!!! warning "Status: planned"
    This quickstart cannot be followed yet. The repository has no Docker
    Compose file and no services to start. Applies to: `dev` (no release
    exists).

This page will become a tutorial that takes a new user from a clean checkout
to telemetry visible in the UI. Until the stack exists and the steps have been
run end to end, it contains no commands, because any command here would fail.

## What the quickstart will cover

1. Start the single-node stack with Docker Compose.
2. Check the health endpoint.
3. Confirm demo traces, logs, metrics and events appear in the UI.
4. Open a trace waterfall and follow a log to its trace.
5. Create an alert and confirm a webhook delivery.

Each step will list the exact command, the expected output and a
troubleshooting link.

## When this page changes status

The banner moves to "prototype, verified on DATE" only after every step has
been run on a clean machine and the outputs recorded here. See Phase 0 in the
[roadmap](../project/roadmap.md).
